# Rad Shields for Chrome

Blocks ads, trackers, pop ups and fake download buttons in Google Chrome.

## Download

**[Download Rad Shields 1.3.2](https://github.com/gbmurad/rad-shields/releases/latest/download/Rad-Shields-Chrome-1.3.2.zip)**

## Install

1. Unzip the file. You get a folder called `rad-shields`.
2. In Chrome, open `chrome://extensions`.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and pick the `rad-shields` folder.
5. Pin Rad Shields from the puzzle piece icon so the shield shows in your toolbar.

Keep the folder where it is after installing; Chrome runs the extension from it.

## Using it

Click the shield to turn protection on or off for a site, pick Lite, Balanced or Strict, or open Settings.
